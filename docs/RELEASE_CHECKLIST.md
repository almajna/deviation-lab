# Final release checklist — stop/go

- [ ] Dataset provenance, access rights, per-task paired outcomes and cost semantics are verified.
- [ ] Repo doesn't include raw third-party data without redistribution permission.
- [ ] Simulated participants are distinctly labeled from observed model outputs.
- [ ] Every critical mechanism has unit/invariant tests and explicit payoffs.
- [ ] At least one verified exploit can be replayed after a clean install.
- [ ] Baselines, holdout split and uncertainty measures are visible.
- [ ] Optional AI-based policy search claims are supported (or feature explicitly disabled).
- [ ] All three visual views work on experiment-backed traces; no fabricated numeric claims.
- [ ] No secrets, unsafe execution or unauthorized costs.
- [ ] Clean-install reproduction with exact commands has been independently checked.
- [ ] External scientific audit completed with no open critical issues.
- [ ] README explains limitations and how to run the project.
- [ ] Evidence-backed internal rubric at least 90/100 (see `docs/ACCEPTANCE.md`).
- [ ] Human research director authorizes public release.
