# REUSABLE PROMPT — user phone check-in / executive status

Inspect the **actual** repository, issues, PRs and CI. Return at most 180 words:
1. Latest merged milestone and evidence link.
2. Active agents/sessions actually known to be running (or explicitly unknown).
3. Blockers and failed checks.
4. Next critical-path task and responsible owner.
5. Cost incurred/authorized and remaining approvals.
6. Current evidence-backed release score (never estimate nonexistent evidence).

Use verified facts only. Never imply a prompt created an autonomous background job. Explain technical blockers in simple terms. Make at most one human decision request per report if possible.
