# Frozen prospective protocol FG-1

**Design frozen in the feasibility PR. Execution blocked pending custodian receipt, implementation review and owner approval.** This is one experiment on a new source. It is separate from the existing final holdout. No data-dependent criterion or substitution is allowed. Report a blocked experiment if a required gate fails.

## Population and information

- Use only the pinned LiveBench math and reasoning candidates in the [audit](FEASIBILITY_DATA_AUDIT.md). Fixed routes are `gpt-4o-mini-2024-07-18` and `gpt-4o-2024-08-06` in that order. Refuse unresolved aliases. Require one finite grade in [0,1] per model per item and matching prompt provenance. Use items active in the 2024-11-25 LiveBench release with one text turn. Use paired outcomes for evaluation and offline settlement.
- Normalize NFKC, casefold and collapse whitespace. Group identical text and connected pairs with normalized word 5-gram Jaccard ≥0.90, using exact matching for shorter prompts. Retain the earliest item per group, tie by source ID. Exclude matches to prior development-only hashes. Sort eligible representatives by SHA-256 of UTF-8 `FG-1|split|<question_id>`, tie by question ID. First 128 are prospective test, next 32 are development, and the remainder train. Require ≥80 train before fitting. Report missingness by model, task family and release date before exclusions. Coverage below 240 stops execution. Development is reserved for dry-run checks and cannot alter rules or fit estimators. This is a within-release holdout by prompt group. Sort training IDs by SHA-256 of UTF-8 `FG-1|history|<question_id>`, tie by question ID. Assign alternating histories to center then provider. The custodian delivers each projection only to its assigned learner. The report-independent parity control alone receives both histories.
- A custodian seals test grades and labels before the implementation team receives input. The router, reporters and attack solver receive only prompt, opaque ID, budget, reservation, permitted history and training-derived predictions. Never use current outputs, grades, actual response length, oracle uplift or post-decision metadata. Commit inputs, split/source hashes, source revisions and executable code hash before evaluation. Assert allocation and attack witnesses are bit-identical after independently permuting or redacting sealed test grades behind the formation interface, with membership fixed after the eligibility audit. Review the boundary before unsealing.
- Sort by SHA-256 of UTF-8 `FG-1|batch|<question_id>` within each test task type, then distribute round-robin into a common sequence in lexicographic task-type order, skipping exhausted types. Group consecutive eight distinct items, discard only the final incomplete batch. Use every full batch once. Define affiliated jobs as positions 0–3 in each batch before any reports. Primary reservation budget is `8*3 + 4*47`, capacity at most four upgraded jobs. Sensitivities use 2 and 6 instead of 4, updating both constraints. All policies use exactly one route per job with lexicographic ties favoring route 0. Costs are standardized reservation units, separate from simulated transfers. Dataset acquisition and evaluation spend must remain $0.

## Locked mechanisms and forecasts

1. **Public-only comparators.** Exact nominal batch allocation, published Q10 batch allocation with bootstrap kNN-5, and the same Q10 assignment with bootstrap XGBoost. Use only the center’s assigned historical outcomes for the binary event score ≥0.5. Public features are normalized word unigram counts mapped by SHA-256 to 4,096 unsigned bins and L2 normalized. Use cosine kNN ranks, tie by opaque training ID. Boost separately per route with XGBoost 3.2.0, 100 trees, depth 3, learning rate 0.05, binary logistic objective, subsample and colsample 1, histogram tree method and one CPU thread. Use the script's 100 paired training bootstrap draw indices, seed 34017, and tenth-smallest prediction as Q10. Nominal uses the unresampled XGBoost point forecast. Floor scores to units of 1/10,000. A constant training label yields its constant prediction. Compare the primary clean result against all three public-only comparators, with no test winner selection.
2. **Scored direct reports.** Anchor each cell at the public XGBoost Q10 estimate. Simulate one provider's auxiliary belief using nominal kNN-5 with the same public features and ranking conventions as the center, fitted on the provider’s disjoint assigned history. Snap to nearest `{0.05,0.10,...,0.95}`, ties down and endpoints clipped. This is synthetic asymmetric access to recorded historical outcomes. The capped score is anchor plus half the reporter's deviation from anchor, after clipping the deviation to [−0.10,0.10]. The uncapped score is anchor plus half the full deviation. Floor allocation scores to units of 1/10,000. Hold all other rules constant. Each arm is scored offline by `1−(r−Y)^2` credit, on the reported probability before clipping. Reserve 16 credits for a batch. Expected loss from deviation is the exact rational sum of `(r−q)^2` over changed reports, with q the provider's fixed honest grid belief. Transfers and outside gains do not fund execution costs.
3. **Information-parity public control.** With access to both histories, compute the provider’s exact auxiliary estimate centrally and apply the capped score map without accepting reports. Its clean allocation must match capped direct reports on every batch, and its threshold is structurally infinite. This control establishes that the simulated signal can be centralized when both histories are accessible. Treat the other three public controls as restricted-information baselines.
4. **Market diagnostic.** Use the same per-cell belief grid, anchor clipped to [0.05,0.95], and an LMSR with liquidity 1 credit per independent binary contract. The sole terminal reporter sets the price to r by the exact cost-function log-odds update, using the final price as the allocation score and log score difference as its transfer. Reserve 48 credits for gross purchases and 48 for maker loss, bounds exceeding `16 log(19)` over the stated grid and initial price interval. Run the direct arms under the same caps. Direct forecasters need no stake. Report actual modelled commitments, expected transfer and realized transfer separately. The market diagnostic has no multi-trader information advantage by design. The direct sequential log-score implementation that replicates the same price update is an algebraic control. Any comparison with the capped direct rule is descriptive because their score mappings and scoring losses differ.

These comparators implement the matched-information question. EA-RAM and STAR have distinct private types, procurement/settlement contracts and objectives. Their published guarantees are scope controls rather than numbers on the primary leaderboard.

## Certification and evaluation

Allow one final provider to change at most two of the 16 task–route reports to any grid value. All remaining messages equal the honest belief. The forecaster sees the same public input as the checker and its declared q. Its external reward is v credits per affiliated job routed to route 1. Define k as the resulting count minus the honest count. For every action with k>0, compute L, the expected transfer loss from the honest action. The threshold is `tau=min L/k`, or +infinity when no feasible action increases exposure. This is the infimum for *strictly* profitable targeted reallocation. At equality select honesty. For other ties prefer fewer edits, then lexicographic report vector.

Enumerate all 1 + 16·18 + choose(16,2)·18² = 39,169 legal actions per batch, including honesty. For direct reports, compare exact integer/rational thresholds. An independent implementation must reconstruct the legal action set and compare with full route enumeration (at most 256 assignments), verifying both the minimum and a witness. Cache identical allocation inputs. Preserve best responses at v in {0,0.01,0.05,0.10,0.25,1.00} by maximizing v·k−L. Market expected loss is Bernoulli KL divergence, summed over edits. Use outward intervals for the market diagnostic, with width ≤10⁻⁸ credits or retain an unresolved interval. Treat ambiguous profitable signs as unresolved rather than pass. Do not change the action set if runtime is high. Stop and report resource failure if either the primary producer or the verifier exceeds its own 2 CPU-hour cap on one local core. At v=0 require zero positive deviation gain. Public-only policies have no forecast manipulation channel, so report +infinity structurally.

After forecasts, certificates and attack choices are committed, the evaluator joins sealed grades. Report clean accuracy, adversarial accuracy, loss versus honest assignment, realized credits, transfer liability, assignment costs and certified threshold distribution, including +infinity and unresolved counts. Use the full-information oracle only to characterize achievable quality. Primary v=0.10 credit per additional affiliated assignment. Report all predeclared v and budget settings without selecting a favorable one. Thresholds are conditional on the fixed beliefs and permitted edits. Welfare changes are measured after the choice and do not enter the attack objective.

## Decision rule

**Hypothesis.** Under the imposed history-access restriction, at the primary budget and v, capped influence preserves useful routing information and materially reduces profitable targeted exposure relative to the uncapped score.

Use one-sided 95% paired percentile bounds from 10,000 whole-batch bootstrap draws, seed 45031. Resample the same batches across policies. Intervals are conditional on the sampled release and public task mix, and may be optimistic for repeated task templates. Report leave-one-task-type-out sensitivity without reselecting rules. The single primary claim is a conjunction and passes only if every gate below passes.

- The lower bound for capped clean accuracy minus each of the three restricted-information public comparators exceeds +0.02 absolute. The lower bound for capped minus uncapped clean accuracy exceeds −0.01.
- The uncapped arm has a profitable targeted action at v=0.10 in at least 20% of batches and mean realized attack-induced accuracy loss is at least 0.01. These minimum-effect gates prevent calling an inert attack surface progress.
- The lower bound for the uncapped minus capped fraction of batches with tau < 0.10 exceeds +0.10 absolute. The lower bound for uncapped minus capped realized attack-induced loss exceeds zero. Require all primary proofs to verify, zero budget breaches and exact clean parity with the information-parity public control.

The practical cutoffs are prospective project judgments, without a power estimate based on test data. Failure to pass any cutoff yields no GO for the scientific claim. Report whether the outcome contradicts the point-effect target, is inconclusive, or is blocked by data or verification. Public-only immunity is a tradeoff reference. A pass supports a conditional clipping tradeoff under imposed access restrictions. A mechanism advantage would require a genuinely access-restricted provider signal with auditable decision-time provenance. With both histories the information-parity control already matches clean quality and removes the attack channel. Neither result establishes equilibrium truthfulness, deployment welfare or real-provider behavior.
