# Exact finite validation protocol, written before exhaustive enumeration

Reference: Test-Time Compute Games v3, https://arxiv.org/html/2601.21839v3, Section 2, Equation 7 and Theorems 1–2. This is a bounded synthetic formal diagnostic, not an empirical dataset result. An exploratory seeded implementation had already been run; this systematic check is a verification of a proposed mathematical repair, not a preregistration of discovery.

1. First execute the two-provider exact-rational counterexample supplied to this independent reviewer; enumerate all four profiles, winner (including abstention), utilities, all unilateral deviations, and identify equilibrium. Verify that the original Equation 7 decreases on an improving deviation for every constant C by checking that both profiles have the same second-best provider value and the provider-only winner margin falls from 1 to 1/2.
2. Build the following complete finite family independently of observed outputs. Two providers each have two actions. Shared deterministic cost vector c=(1/4,1/2); quality q ranges over all weakly nondecreasing pairs from {0,1/2,1,3/2,2}; positive margin m ranges over all strictly increasing pairs from {1/4,1/2,3/4,1}; p=c+m. Exclude a game if any achievable value ties abstention V0=0 or any provider-1 value ties any provider-2 value. This yields finitely many legal games; do not alter the domain after execution.
3. Enumerate every profile and unilateral deviation. Calculate exact utilities, profitable deviations, and pure NE with Fraction. For each game define δ as the smallest positive difference between achievable values from distinct participants, including the outside dummy, and mmin,mmax across all available margins plus dummy margin 1. Define C=1+(mmax-mmin)/δ. Corrected candidate Φ=margin(winner)+C·second-highest value among providers and outside. Verify every strictly profitable deviation strictly increases Φ, using only Fraction.
4. For each profile, check this necessary-and-sufficient equilibrium characterization: if V1*<V0, all profiles are equilibria. Otherwise let d be the unique maximum-value provider and T=max(V0, all other providers' maximal values); require its selected action to maximize the action ordering subject to value>T, and require no higher-profit action to beat max(V0, other providers' current values). Compare against direct exhaustive deviations for every profile.
5. Print games/profiles/deviations, false matches, exact counterexample and SHA-256 of the script. This confirms only the bounded enumeration; the accompanying case proof must stand on its own. No statistical significance or generality is inferred from the finite sample.
