# Product

## Platform

web

## Stack

Vite + React + TypeScript static site (per `docs/VISUAL_SPEC.md`). No backend, no secrets, no paid services in the bundle.

## Users and job

AI enthusiasts, engineers, researchers and technically curious people, including beginners. Within ~30 seconds a first-time visitor should grasp what is being shown; deeper technical detail (event payloads, provenance, accounting identities) is available on interaction. The experience reads like an interactive video essay: the visitor controls pacing (play, pause, step, seek).

## What it makes possible

DEVIATION replays completed resource-allocation experiments with autonomous AI agents as an evidence-driven laboratory: every number on screen traces to a specific event record, and the interface distinguishes what participants knew at action time (PUBLIC events) from what was revealed only after settlement (POST_SETTLEMENT events).

## Durable constraints

- Trace-driven only. All displayed metrics derive from contract v0.2 completed-trace events (`docs/CONTRACTS.md`). Swapping a fixture for a genuine exported trace requires no code rewrite.
- Current data is a 7-event `SYNTHETIC` conformance fixture (1 economic agent, 2 tasks). It must be conspicuously labeled synthetic and never presented as a discovery or mechanism result.
- Market prices, attack causality and mechanism-evolution results do not exist yet (need Phase 3/4 event types). These views render honest "not yet available" states, never fabricated charts.
- Forecast values are E[judged preference reward], a noisy proxy — never "probability of coding success".
- Reserved cost, realized cost (nano synthetic units) and virtual credits are separate quantities; never summed or converted.
- No private-signal inspection in the public replay.
- Accessible keyboard control, reduced motion, phone layouts.
